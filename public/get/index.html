Setting up a fingerprint door

  1. ZKFinger SDK for Windows — this carries the ZK9500 driver. Plug the scanner in afterwards and check the SDK's own demo can read a finger. If it cannot, stop there; nothing else will work.
  2. Node.js 20 or newer — nodejs.org, the LTS installer, all defaults. This is separate from the ZKTeco driver and it is the step people skip. Nothing else has to be installed: the download carries its own parts. Node does have to match the SDK — 64-bit with 64-bit — and the self-test says so if they disagree.
  3. Unzip the door agent somewhere permanent, like C:\MBA door.
  4. Double-click SETUP.bat and answer its questions. That is the whole setup: what this machine is, which shop, a Desktop shortcut, and whether it starts with Windows. Right-click it and choose Run as administrator if you want that last part.
  5. From then on, one thing to click: the shortcut on the Desktop, or OPEN-THE-CLOCK.bat in that folder. It starts the door if it is not already running and then opens it — no need to know whether it was on.
  6. Something not working? SELF-TEST.bat checks the scanner one call at a time and says which one failed.

Double-click SETUP.bat and answer four questions. It asks whether this machine is the office desk or one of the two doors, writes the settings, puts a shortcut on the Desktop and offers to start it with Windows. A desk holds the scanner for enrolling and clocks nobody on — which matters, because enrolling sixty-seven people means sixty-seven fingers on the glass, and at a door every one of those would be somebody's arrival.

Enrolling is done at http://127.0.0.1:9500/office on the door PC — the back office, served through the door so it can reach the scanner. Sign in as yourself, then Team → Edit → Fingerprints → Scan a finger. It takes the finger three times and merges them, so lift between presses. Enrol two fingers each — a cut thumb on a Monday should not cost somebody their hours.

Installing on Android

  1. Tap a download above on the phone itself.
  2. Android will warn about installing outside the Play Store — choose Settings and allow this browser to install apps.
  3. Open the downloaded file and tap Install.

Every app here is a thin shell around this website, so everything we add reaches your phone without reinstalling. A new download is only needed when the app itself changes — a new name, a new icon, a new address.
